# PragyaSuchi

**PragyaSuchi** is a branded Hindi and English smart grocery-list experience designed for everyday household shopping.

Live experience: https://smart-shopp.web.app

## The idea

Shopping lists should feel immediate, familiar, and useful. PragyaSuchi turns the traditional paper list into a connected digital experience while keeping the simple checklist at its center.

It helps people plan, remember, and complete grocery shopping with less repeated typing and less friction between devices.

## What makes it different

Traditional grocery lists are often handwritten, easy to lose, difficult to update, and disconnected from the way people shop today. PragyaSuchi brings practical digital tools into the same focused workflow:

- Hindi and English support for a more natural household experience.
- Voice input for quick, hands-free additions.
- Optional bill scanning to reduce manual entry.
- Offline-ready behavior for unreliable connections and everyday mobility.
- Cloud-connected personal lists for continuity across devices.
- Installable PWA experience without requiring an app-store download.
- Search, quantities, units, budget tracking, print support, themes, and fasting-mode controls.

The product is intentionally simple at the point of action. Its difference is not complexity; it is the combination of familiarity, bilingual design, automation, and continuity.

## Technology

- **Frontend:** HTML, CSS, modern browser JavaScript
- **UI:** Tailwind CSS CDN and custom local styles
- **Authentication:** Firebase Authentication with Google sign-in
- **Database:** Cloud Firestore with user-owned grocery documents
- **Deployment:** Firebase Hosting with HTTPS and SPA routing
- **Offline experience:** Service Worker and Web App Manifest
- **Voice input:** Browser Web Speech API
- **Optional intelligence:** Google Gemini integration for bill-image recognition
- **Brand assets:** Local SVG artwork for the app identity, PWA icons, category visuals, and social preview

## How we built it

PragyaSuchi was built as a focused product effort combining:

- Product thinking around real household shopping habits
- Bilingual Hindi and English content design
- Responsive frontend engineering
- Firebase authentication and cloud data integration
- Offline-first Progressive Web App behavior
- Voice and image-assisted input
- Accessible, mobile-friendly interaction design
- Brand identity, visual assets, and deployment operations

The project uses a framework-light architecture so the core experience remains understandable, maintainable, and fast for a small product team.

## Team and effort

PragyaSuchi represents the combined effort of product designers, frontend developers, Firebase engineers, content contributors, and testers. Every part of the experience, from bilingual item naming to offline behavior and local brand artwork, is shaped around making routine shopping more dependable.

The team values clear interfaces, useful automation, privacy-conscious cloud design, and improvements that solve a real shopping problem instead of adding technology for its own sake.

## Brand direction

PragyaSuchi means a thoughtful, intelligent list. The brand stands for:

- **Clarity:** Know what to buy before entering the store.
- **Continuity:** Keep the list available across sessions and devices.
- **Inclusion:** Make the experience comfortable in Hindi and English.
- **Practical intelligence:** Use voice and image input where they genuinely save time.
- **Trust:** Keep personal grocery data separated by user account.

## Project status

PragyaSuchi is a deployed product experience running on Firebase Hosting. The repository contains the frontend application, local visual assets, PWA configuration, Firebase integration, and deployment configuration used to build the product.
